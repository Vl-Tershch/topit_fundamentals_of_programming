# Как это устроено — простыми словами

## Что такое ветка (branch)

Ветка — это «версия» проекта. У вас в репозитории их четыре:

| Ветка | Что внутри |
|-------|------------|
| `main` | только `.gitignore` и `requirements.txt` — тут живёт «общая часть» проекта |
| `lab_1` | папка `lab_01` (первая лабораторная) |
| `lab_2` | папка `lab_02` (вторая лабораторная) |
| `lab_3` | пока пустая копия старого `main` — можно удалить, если не нужна |

Файлы при переносе **не удалились**: они лежат в `lab_1` и `lab_2`, и даже в истории `main`
старая версия осталась. Ничего не потеряно.

## Как посмотреть это на GitHub (без командной строки)

1. Откройте https://github.com/Ergonomid/topit_fundamentals_of_programming_Kislitca_KA
2. Над списком файлов слева есть выпадающий список с надписью **main** — это переключатель веток.
3. Нажмите на него и выберите **lab_1** → увидите только папку `lab_01`.
4. Снова откройте список, выберите **lab_2** → увидите только папку `lab_02`.
5. Выберите **main** → папок с лабами там больше нет.

## Если нужно посмотреть старую версию файла

1. Откройте нужную папку в `main` через переключатель веток — её там уже нет.
2. Тогда просто переключитесь на `lab_1` (или `lab_2`) — файлы там.
3. История изменений: ссылка **History** (часики) справа над файлами.

## Как добавить новую лабораторную (lab_03)

Вам понадобится ветка `lab_3` (она уже есть) или новая:

1. Переключитесь на `main` в списке веток.
2. Создайте папку `lab_03` через **Add file → Create new file**,
   в имени файла напишите `lab_03/task_1.py` — папка создастся сама.
3. Внизу страницы выберите **Create a new branch for this commit** и назовите её `lab_3`.
4. Нажмите **Propose changes** → **Create pull request** → **Merge**.
5. В `main` появится только новый файл, а лабы 01/02 там не вернутся.

## Правила, чтобы не запутаться

- **main = общее.** Только `requirements.txt`, `.gitignore`, README и т.п.
- **lab_N = одна лабораторная.** Внутри только её папка.
- Работайте в своей ветке, потом сливайте в `main` через **Pull request** (кнопка **Merge**).
- Если что-то сломалось — ничего не удаляйте в панике: старые версии всегда есть в **History**.
