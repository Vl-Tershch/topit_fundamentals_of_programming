# Лабораторная работа № 1. Выполнение программы, объекты и базовые типы Python

## 1. Общая информация

**Темы курса:**

1. Python, CPython и модель выполнения программы.
2. Типы данных и объектная модель Python.

## 2. Цель работы

Разобраться, как CPython выполняет программу, научиться отличать имя от объекта, корректно применять операции сравнения и работать с базовыми типами данных Python.

## 3. Планируемые результаты

После выполнения работы студент должен уметь:

- запускать Python-код в REPL и из `.py`-файла;
- объяснять путь программы от исходного текста до выполнения байткода;
- различать выражения и инструкции;
- объяснять связывание имен с объектами;
- использовать `type()`, `id()`, `==` и `is` по назначению;
- работать с `int`, `float`, `bool`, `complex`, `str` и `None`;
- выполнять явные преобразования типов;
- объяснять погрешность вычислений с числами с плавающей точкой;
- применять индексацию, срезы, Unicode и форматирование строк.

## 4. Условия выполнения

1. Используйте Python 3.11 или новее.
2. Разместите решение в отдельной директории `lab_01`.
3. Для каждого задания создайте отдельный файл: `task_1.py`, ..., `task_5.py`.
4. Нельзя использовать условия, циклы, коллекции, пользовательские функции и обработку исключений: эти конструкции рассматриваются в следующих темах курса.
5. Все программы должны запускаться без изменения исходного кода командой:

   ```bash
   python task_1.py
   ```

6. Там, где требуется прогноз результата, сначала запишите прогноз в комментарии и только потом выполните программу.
7. Результаты наблюдений и ответы на вопросы оформите в файле `REPORT.md`.

## Задание 2. Имена, объекты и сравнение

Создайте `task_2.py` и исследуйте следующий код:

```python
a = 1000
b = a
c = int("1000")

print("Типы:", type(a), type(b), type(c))
print("Идентификаторы:", id(a), id(b), id(c))
print("a == b:", a == b)
print("a is b:", a is b)
print("a == c:", a == c)
print("a is c:", a is c)
```

Перед запуском запишите в комментариях прогноз четырех сравнений. После запуска:

1. Представьте связи между именами и объектами в виде текстовой схемы или Mermaid-диаграммы в `REPORT.md`.
2. Объясните разницу между равенством значений и идентичностью объектов.
3. Измените значение `c` на `None` и добавьте корректную проверку того, что `c` обозначает объект `None`.
4. Выполните отдельно следующий фрагмент и объясните результат:

   ```python
   first = "python"
   second = "py" + "thon"

   print(first == second)
   print(first is second)
   ```

5. Сформулируйте правило: когда применять `==`, а когда — `is`.

> Нельзя делать вывод о равенстве значений по совпадению `id()`. Интернирование строк и кеширование некоторых объектов являются деталями реализации. Программная логика не должна от них зависеть.

### Контрольные вопросы

1. Создает ли инструкция `b = a` копию объекта?
2. Что возвращают `type()` и `id()`?
3. Почему `None` принято сравнивать с помощью `is`, а числа и строки — с помощью `==`?

## Задание 3. Числовые типы, операции и преобразования

Создайте `task_3.py`. Программа должна последовательно выполнить четыре мини-эксперимента.

### Эксперимент A. `int` и арифметические операторы

Для значений `x = 17` и `y = 5` выведите результаты и типы результатов операций:

- `x + y`;
- `x - y`;
- `x * y`;
- `x / y`;
- `x // y`;
- `x % y`;
- `x ** y`.

Объясните, почему `/` и `//` возвращают разные значения и могут возвращать результаты разных типов.

### Эксперимент B. Большие целые числа

Вычислите и выведите:

```python
2 ** 1000
```

Объясните, чем целые числа Python отличаются от целых чисел фиксированной разрядности во многих других языках.

### Эксперимент C. `float`

Исследуйте выражение:

```python
result = 0.1 + 0.2
```

Выведите:

- значение `result`;
- результат `result == 0.3`;
- разность `result - 0.3`;
- результат `math.isclose(result, 0.3)`.

Для последней операции импортируйте модуль `math`. Объясните наблюдение через двоичное представление чисел с плавающей точкой и сформулируйте правило их безопасного сравнения.

### Эксперимент D. `bool`, `complex` и явное преобразование типов

Выполните операции и выведите значение вместе с его типом:

```python
int("42")
float("3.14")
str(2026)
bool(0)
bool(-1)
bool("")
bool("False")
complex(2, -3)
```

Объясните, почему `bool("False")` дает истинное значение. Для комплексного числа отдельно выведите действительную и мнимую части.

### Контрольные вопросы

1. Почему результат обычного деления двух объектов `int` имеет тип `float`?
2. В чем отличие преобразования `int("42")` от `int(42.9)`?
3. Какие значения из эксперимента D являются falsy?

## Задание 5. Информационная карточка вычислительного эксперимента

Создайте консольную программу `task_5.py`, объединяющую изученные конструкции.

### Входные данные

Программа должна запросить у пользователя:

- имя исследователя;
- название эксперимента;
- количество выполненных запусков — целое число;
- длительность одного запуска в секундах — вещественное число;
- действительную и мнимую части комплексного коэффициента — два вещественных числа.

Можно считать, что пользователь вводит корректные данные.

### Вычисления

Программа должна без условий и циклов вычислить:

- общую длительность всех запусков в секундах;
- общую длительность в минутах;
- комплексный коэффициент с помощью `complex()`;
- квадрат модуля коэффициента по формуле `real ** 2 + imag ** 2`;
- логическое значение `has_runs`, показывающее, является ли число запусков ненулевым, с помощью `bool()`.

### Результат

Выведите аккуратно оформленную карточку. Пример структуры вывода:

```text
========================================
ЭКСПЕРИМЕНТ: Проверка модели
Исследователь: Анна Смирнова
Запуски: 8
Общее время: 100.00 с (1.67 мин)
Коэффициент: (2-3j)
Квадрат модуля: 13.00
Есть выполненные запуски: True
========================================
```

Дополнительные требования:

1. Для преобразования данных из `input()` явно используйте `int()` и `float()`.
2. Примените f-строки и спецификатор `.2f` для вещественных результатов.
3. Не дублируйте вычислительные выражения внутри `print()` — промежуточные результаты свяжите с понятными именами.
4. Добавьте в начало файла модульную строку документации с кратким описанием программы.
5. После основной карточки выведите диагностическую строку с типами шести введенных значений. Ее оформление выбирается самостоятельно.

### Анализ в отчете

В `REPORT.md`:

1. Для каждого имени из программы укажите, с объектом какого типа оно связано после выполнения соответствующей инструкции.
2. Выберите одну арифметическую строку и разберите ее на литералы, имена, операторы и вызовы функций.
3. Опишите путь программы: исходный файл → разбор исходного текста → AST → компиляция в байткод → выполнение виртуальной машиной CPython.
4. Объясните, почему результат `input()` необходимо явно преобразовывать перед арифметическими вычислениями.

### Контрольный вопрос
