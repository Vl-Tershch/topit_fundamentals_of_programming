## Задание 3. Подсчет ссылок и время жизни объекта

Создайте `task_3.py` и импортируйте модуль `sys`.

Исследуйте изменение счетчика ссылок:

```python
import sys

data = [1, 2, 3]
print("После создания:", sys.getrefcount(data))

alias = data
print("После создания alias:", sys.getrefcount(data))

container = [data]
print("После помещения в контейнер:", sys.getrefcount(data))

del alias
print("После del alias:", sys.getrefcount(data))

container.clear()
print("После очистки контейнера:", sys.getrefcount(data))
```

В отчете объясните:

- почему `sys.getrefcount()` показывает на одну временную ссылку больше;
- какие инструкции увеличивают счетчик;
- какие инструкции уменьшают счетчик;
- почему `del alias` удаляет имя, а не командует напрямую удалить объект.

Дополните программу экспериментом со слабой ссылкой. Для этого создайте простой класс-контейнер:

```python
import weakref


class Record:
    pass


record = Record()
weak_record = weakref.ref(record)

print(weak_record())
del record
print(weak_record())
```

Объясните, почему слабая ссылка не продлевает время жизни объекта. Самостоятельно найдите пример ситуации, в которой слабые ссылки могут быть полезны.

### Практическая задача

Создайте реестр из трех объектов `Record`, используя `weakref.WeakValueDictionary`. Сохраните сильные ссылки на два объекта, а для третьего оставьте только запись в слабом словаре. После удаления временной сильной ссылки проверьте состав реестра и выведите, какие записи продолжают существовать. Затем удалите еще одну сильную ссылку и повторите проверку.

Программа должна на практике показать, что слабый реестр не управляет временем жизни зарегистрированных объектов.
